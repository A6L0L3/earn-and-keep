> 一个以「正当赚钱 + 守住钱」为骨架的商业与投资认知库。把商业逻辑、搞钱路径与投资操作系统重构成**可落地**的体系：从认知定位到行动方法，再到风控与复盘，逐板块递进，配套自检清单。

本仓库是商业认知与投资知识的整理、汇编与重构，属学习研究资料。每篇笔记自足、格式统一，打开即用。

## 板块0 · 学习路径和建议

### 0_1 学习路径

1. **先建立商业认知**：读《发达正道》，把"怎么正当地赚钱"从模糊愿望转成可执行的行动体系。
2. **再建立投资操作系统**：读《金融投资系统知识库》，把资产配置、标的选择、买卖执行与复盘风控写成能照着执行的规则与清单。
3. **用清单落地**：两篇均配自检清单，读完后立即按清单做第一次自查与排雷。
4. **循环复盘**：认知与操作都靠复盘迭代，不建议只"读完"不"做"。

### 0_2 使用建议与边界声明

- 本仓库收录商业认知与投资方法，仅作为学习研究参考；**不构成任何投资建议、理财推荐或商业决策依据**。投资有风险，请理性判断、自担风险。
- 本仓库全部文件由公开或原始资料收集而来，并经 AI 工具重新归纳、整理与结构化；整体格式与大纲参考了「庚戊学堂」的学习模块组织方式。原始资料、厂商文档、教材与考纲的著作权归各自权利人所有，本仓库仅对**整理汇编成果**采用 CC BY 4.0（见文末协议）。二创请注明出处，商业使用前请自行确认合规。
