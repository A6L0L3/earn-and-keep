### 发达正道：商业认知与落地行动体系

整套体系只解决一个问题：**如何正当地赚到钱，并且把钱留住。**

### 从零构建你的投资操作系统 · 金融投资系统知识库

多数人学投资的路径是：读几本书 → 记住几句名言 → 继续盯盘追涨杀跌。问题不在智力，而在**没有把"知道"转译成"做"的规则**。本知识库的全部设计围绕一个目标：把资产配置、标的选择、买卖执行与复盘风控，写成能照着执行的规则与清单，而不是停留在观念层面。

## 库内体例

各文档以「单篇知识库」为通例组织：

1. `XX.md`——合订 / 单篇知识库，一篇读完全体系（本库 2 篇，各自独立成册）；
2. 每篇一级标题只有 1 个（篇名），其下以 `## README · 导览`（其下 `### README_N`）开头，接 `## 板块0 · 学习路径建议`（其下 `### 0_1 学习路径`、`### 0_2 使用建议与边界声明`）→ `## 板块1…N` 主题；小节编号形如 `0_1`、`12_3`，可按主题独立查阅；
3. `读书笔记/`（本库如有）——所据原著的逐本读书笔记。

各篇普遍遵循同一写法：先给学习路径与认知定位，再讲原理与操作流程，最后落到底层公理、避坑清单、速查附录与验证方法。所据原书（PDF/EPUB 等）不在本仓库内，本仓库仅收录整理笔记与知识库。
