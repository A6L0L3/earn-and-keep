# 商业与投资认知库（**`earn-and-keep`**）

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/deed.zh)

> 一个以「正当赚钱 + 守住钱」为骨架的商业与投资认知库。把商业逻辑、搞钱路径与投资操作系统重构成**可落地**的体系：从认知定位到行动方法，再到风控与复盘，逐板块递进，配套自检清单与可执行工具。

本仓库是商业认知与投资知识的整理、汇编与重构，属学习研究资料。每篇笔记自足、格式统一，打开即用；脚本与示例配置统一收口在 `tools/`，开箱即跑。

## README · 导览

### README_1 这是什么，与库内体例

本仓库围绕一个核心问题展开：**如何正当地赚到钱，并且把钱留住**。两份主库各自独立成册，库内体例统一为：

```
# 篇名 · 一句话定位
## README · 导览
### README_1 子板块名称
### README_2 子板块名称
## 板块0 · 学习路径和建议
### 0_1 学习路径
### 0_2 使用建议与边界声明
## 板块1…N · 主题板块
### 1_1 子板块名称
```

- 每篇一级标题只有 1 个（篇名），其下以 `## README · 导览`（`### README_N`）开头，接 `## 板块0 · 学习路径和建议`（`### 0_1 学习路径`、`### 0_2 使用建议与边界声明`），再接主题板块 `## 板块1…N`；小节编号形如 `0_1`、`12_3`，可按主题独立查阅。
- 各篇普遍遵循同一写法：先给学习路径与认知定位，再讲原理与操作流程，最后落到底层公理、避坑清单、速查附录与验证方法。
- 投资主库内嵌的可运行脚本与示例配置已统一迁出到仓库根的 `tools/` 目录（见 README_4），正文以引用方式指向，避免双重维护。

### README_4 配套工具 `tools/`

投资主库内嵌的计算器已统一迁出到仓库根的 `tools/`，源码与正文各存一份引用，避免发散。运行需 Python 3.8+，全部脚本**仅依赖 Python 标准库**，无需安装第三方包。

| 脚本 | 用途 | 对应板块 | 运行示例（在仓库根目录执行） |
| --- | --- | --- | --- |
| `fire_calc.py` | 财务自由年限测算 | 知识库二·板块1 | `python3 tools/fire_calc.py --config tools/fire.json` |
| `finance_check.py` | 个人财务体检 | 知识库二·板块1 | `python3 tools/finance_check.py --config tools/my_finance.json` |
| `reverse_dcf.py` | 逆向 DCF 估值 | 知识库二·板块5 | `python3 tools/reverse_dcf.py --price 100 --fcf 2.0 --r 0.10` |
| `valuation.py` | 价值估值计算器 | 知识库二·板块5 | `python3 tools/valuation.py --config tools/demo.json` |
| `position.py` | 仓位管理器 | 知识库二·板块6 | `python3 tools/position.py --p 0.6 --b 2.5` |
| `rebalance.py` | 组合再平衡计算器 | 知识库二·板块7 | `python3 tools/rebalance.py --config tools/portfolio.json` |

- 不带参数直接运行脚本可跑通内置示例；要自定义数据，修改对应的 `tools/*.json` 后用 `--config tools/<文件名>.json` 传入。
- 各脚本的完整源码、字段说明与原理见 [《金融投资系统知识库》](<./金融投资系统知识库.md>) 对应板块（正文以 `**脚本文件**` / `**示例配置**` 引用 `tools/` 下文件）。

## 板块0 · 学习路径和建议

### 0_1 学习路径

1. **先建立商业认知**：读《发达正道》，把"怎么正当地赚钱"从模糊愿望转成可执行的行动体系。
2. **再建立投资操作系统**：读《金融投资系统知识库》，把资产配置、标的选择、买卖执行与复盘风控写成能照着执行的规则与清单。
3. **用工具落地**：需要量化时跑 `tools/` 下的脚本（财务体检、估值、仓位、再平衡等），把判断从"感觉"变"计算"。
4. **用清单复盘**：两篇均配自检清单与复盘模板，读完后立即做第一次自查与排雷，并循环迭代。

### 0_2 使用建议与边界声明

- 本仓库收录商业认知与投资方法，仅作为学习研究参考；**不构成任何投资建议、理财推荐或商业决策依据**。投资有风险，请理性判断、自担风险。
- 本仓库全部文件由公开或原始资料收集而来，并经 AI 工具重新归纳、整理与结构化；整体格式与大纲参考了「庚戊学堂」的学习模块组织方式。原始资料、厂商文档、教材与考纲的著作权归各自权利人所有，本仓库仅对**整理汇编成果**采用 CC BY 4.0（见文末协议）。二创请注明出处，商业使用前请自行确认合规。
